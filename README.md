# Movie Recommendation System with Collaborative Filtering

This is my Machine Learning final exam project. The project builds a simple movie recommendation system using the MovieLens 100K dataset.

## What the project contains

- `movie_recommendation_system.ipynb` - main Jupyter notebook
- Data download code inside the notebook
- Exploratory data analysis
- User-based collaborative filtering
- Item-based collaborative filtering
- RMSE and MAE evaluation
- Final discussion and conclusion

## How to run it

1. Open the notebook in Jupyter Notebook or JupyterLab.
2. Run the cells from top to bottom.
3. The dataset will be downloaded automatically into a `data` folder.

## Libraries used

- pandas
- numpy
- matplotlib
- scikit-learn

## Project idea

The goal is to recommend movies to users based on rating patterns. If users have similar ratings, they may also enjoy similar movies. This is called collaborative filtering.
